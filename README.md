# GTA VI HUB 🎮🌴

یک وب‌سایت هواداری کامل و **کاملاً رسپانسیو** برای دنیای *Grand Theft Auto VI* — الهام‌گرفته از ساختار سایت‌های دیتابیس GTA، با تم نئونی Vice City (صورتی/نارنجی/فیروزه‌ای) و طراحی اختصاصی.

A fully responsive GTA 6 fan hub with a neon Vice City theme: interactive map, vehicle database, character profiles, weapons stats, news and cheats.

## ✨ امکانات

| بخش | توضیح |
| --- | --- |
| **خانه** | هیرو نئونی، شمارنده‌های متحرک، دسترسی سریع، آخرین اخبار، خودروهای شاخص، چیت‌های پرکاربرد |
| **وسایل نقلیه** | دیتابیس ۱۴ خودرو با جست‌وجوی زنده، فیلتر کلاس، مرتب‌سازی بر اساس سرعت/هندلینگ/نام و نوار آمار |
| **نقشه** | نقشه‌ی SVG ایالت لئونیدا با نشانگرهای تعاملی، فیلتر منطقه و کارت توضیحات |
| **شخصیت‌ها** | پروفایل Lucia، Jason و دیگر شخصیت‌ها با زندگینامه و آمار |
| **سلاح‌ها** | مقایسه‌ی قدرت، سرعت شلیک و برد هر سلاح |
| **اخبار** | فهرست اخبار با فیلتر دسته‌بندی و جست‌وجو |
| **چیت‌ها** | کدهای PS5/Xbox با دکمه‌ی کپی یک‌کلیکی |

## 🧱 تکنولوژی

- HTML5 + CSS3 + Vanilla JavaScript — **بدون نیاز به build یا وابستگی**
- طراحی **RTL** و فونت فارسی Vazirmatn
- تم تیره نئونی، گرادیان‌های GTA 6، افکت‌های hover و انیمیشن اسکرول
- رسپانسیو کامل: دسکتاپ، تبلت و موبایل (شامل منوی همبرگری و استک کارت‌ها)
- پشتیبانی از `prefers-reduced-motion` و حالت فوکوس برای دسترس‌پذیری

## 📁 ساختار

```
.
├── index.html            # صفحه اصلی
├── vehicles.html         # دیتابیس وسایل نقلیه
├── map.html              # نقشه تعاملی لئونیدا
├── characters.html       # شخصیت‌ها
├── weapons.html          # سلاح‌ها
├── news.html             # اخبار
├── cheats.html           # چیت‌کدها
└── assets/
    ├── css/style.css     # تمام استایل‌ها و ریسپانسیو
    └── js/
        ├── data.js       # داده‌های سایت (قابل ویرایش)
        └── app.js        # رندر، فیلتر و تعامل‌ها
```

## 🚀 اجرا

کافی است `index.html` را باز کنید. یا برای اجرای محلی:

```bash
npx serve .
# یا
python -m http.server 8000
```

## 🌐 انتشار روی GitHub Pages

1. تنظیمات مخزن → **Pages**
2. Source: **Deploy from a branch** → Branch: `main` / root
3. سایت روی `https://sahandse.github.io/gta6/` در دسترس خواهد بود.

## ✏️ ویرایش داده‌ها

همه‌ی محتوا در `assets/js/data.js` است. برای افزودن خودرو:

```js
{ name: "اسم ماشین", cls: "Super", maker: "برند", speed: 95, handling: 88,
  price: "$2,000,000", tags: ["تگ"], color: ["#ff2d95", "#ff8a00"] }
```

نقشه، شخصیت‌ها، سلاح‌ها، اخبار و چیت‌ها هم در همان فایل با ساختار مشابه تعریف شده‌اند.
