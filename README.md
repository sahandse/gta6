# GTA VI HUB 🎮🌴

یک وب‌سایت هواداری کامل و **کاملاً رسپانسیو** برای دنیای *Grand Theft Auto VI* — الهام‌گرفته از ساختار سایت‌های دیتابیس GTA، با تم نئونی Vice City (صورتی/نارنجی/فیروزه‌ای) و طراحی اختصاصی.

A fully responsive GTA 6 fan hub with a neon Vice City theme: interactive map, vehicle database, character profiles, weapons stats, news and cheats.

## 🧱 تکنولوژی

- HTML5 + CSS3 + Vanilla JavaScript — **بدون نیاز به build یا وابستگی**
- طراحی **RTL** و فونت فارسی Vazirmatn
- تم تیره نئونی، گرادیان‌های GTA 6، افکت‌های hover و انیمیشن اسکرول
- رسپانسیو کامل: دسکتاپ، تبلت و موبایل (شامل منوی همبرگری و استک کارت‌ها)
- پشتیبانی از `prefers-reduced-motion` و حالت فوکوس برای دسترس‌پذیری

## 🚀 اجرا

کافی است `index.html` را باز کنید. یا برای اجرای محلی:

```bash
npx serve .
# یا
python -m http.server 8000
```

## 🌐 انتشار روی GitHub Pages

1. تنظیمات مخزن → **Pages**
2. Source: **Deploy from a branch** → Branch: `main` / root
3. سایت روی `https://sahandse.github.io/gta6/` در دسترس خواهد بود.

## ✏️ ویرایش داده‌ها

همه‌ی محتوای GTA در `assets/js/data.js` و فهرست ابزارها در `assets/js/resources.js` است. برای افزودن خودرو:

```js
{ name: "اسم ماشین", cls: "Super", maker: "برند", speed: 95, handling: 88,
  price: "$2,000,000", tags: ["تگ"], color: ["#ff2d95", "#ff8a00"] }
```

نقشه، شخصیت‌ها، سلاح‌ها، اخبار و چیت‌ها هم در همان فایل با ساختار مشابه تعریف شده‌اند. برای افزودن منبع جدید به صفحه‌ی منابع، یک آیتم به دسته‌ی مناسب در `resources.js` اضافه کنید:

```js
{ name: "Tool", fa: "نام فارسی", desc: "توضیح کوتاه",
  url: "https://example.com", license: "MIT · رایگان", tag: "free" } // یا tag: "freemium"
```

## ⚠️ سلب مسئولیت

این پروژه یک **پروژه‌ی هواداری مستقل** است و هیچ وابستگی به Rockstar Games یا Take-Two Interactive ندارد. تمام علائم تجاری و دارایی‌های بازی متعلق به صاحبان اصلی آن‌هاست. محتوای این سایت نمونه/نمایشی است.


### نقشه تعاملی و دیتابیس مکان‌ها

- داده‌های پایه نقشه در `assets/data/locations.json` نگهداری می‌شوند.
- مکان‌های دارای `official: true` نام‌شان در منابع رسمی Rockstar معرفی شده؛ این برچسب به معنی تأیید مختصات دقیق نیست.
- مختصات `x` و `y` درصدهای تقریبی روی پوستر نقشه هستند، نه مختصات GPS یا مسیر واقعی بازی.
- علاقه‌مندی‌ها، مکان‌های بازدیدشده، تم و مکان‌های اضافه‌شده در ابزار مدیریت محلی با `localStorage` همان مرورگر ذخیره می‌شوند.
- از ابزار مدیریت نقشه می‌توان JSON را خروجی گرفت؛ برای انتشار تغییرات عمومی، فایل `assets/data/locations.json` را در GitHub به‌روزرسانی کن.
- GitHub Pages بک‌اند یا احراز هویت مدیریتی ندارد؛ ابزار مدیریت داخل صفحه فقط برای ویرایش محلی است.


### دیتابیس نقشه Leonida

- دیتابیس مکان‌ها: `assets/data/places.json` — ۱٬۰۱۱ رکورد نام‌گذاری‌شده از Open GTA 6 Map.
- مرزهای ناحیه: `assets/data/districts.json` — مرزهای جامعه‌محور و تقریبی.
- داده و کاشی‌های نقشه با مجوز **CC BY 4.0** از [Open GTA 6 Map](https://github.com/fbritoferreira/gta6) استفاده شده‌اند. اعتباردهی در خود نقشه و فایل `assets/data/SOURCES.md` درج شده است.
- ۸ رکورد دسته fence و ۲ مورد با نام صریح bar/tavern از نسخه واردشده کنار گذاشته شده‌اند.
- مختصات و مرزها جامعه‌محور و تقریبی هستند؛ نام ۶ منطقه اصلی جداگانه از منبع رسمی Rockstar ارجاع داده شده است.
- کاشی‌های روز/شب از میزبان GitHub Pages منبع دریافت می‌شوند؛ بنابراین نمایش نقشه پایه برای بارگذاری به اینترنت نیاز دارد.
- علاقه‌مندی، بازدیدها و مکان‌های شخصی فقط در مرورگر کاربر ذخیره می‌شوند.
